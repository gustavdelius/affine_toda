# Verification code for the book

Scripts behind the symbolic and numerical checks of the textbook material in Parts I–IV (`part1-background/` to `part4-real-coupling/`), the textbook parts of Parts V–VI, Part VII on the half-line (`part7-half-line/`; the `boundary_*`, `shg_boundary_*`, `reflection_matrices`, `qsp_checks`, `particle_reflection`, `soliton_preserving`, `an_nondiagonal_scalar`, `boundary_krein`, `dn_uniform`, `dn_nondiagonal_scalar`, `solitonic_linear`, `sp_scalar` and `boundary_dirichlet` scripts), Part VIII on defects (`part8-defects/`; the `defect_*` scripts) and appendix A. Python 3 with numpy, sympy and mpmath. Each script in this directory runs on its own and prints one `PASS` or `FAIL` line per check. The subdirectories hold the larger computations behind Parts V, VI and IX; they are listed under "Subdirectories and research scripts" below.
