# Superalgebra Toda theories

Checks for the chapter on affine Toda theories based on Lie superalgebras (`part4-real-coupling/16-superalgebra-toda.qmd`, `sec-super-toda`) and for the note on supersymmetric scattering in `sec-known-smatrices-notes`. Python 3 with numpy, scipy, sympy and mpmath. Run each script from the repository root, for example `python3 code/super_toda/components.py`. Each prints one `PASS` or `FAIL` line per check and exits with status 1 if any check fails.

| Script | Book location (ids) | What it checks | Checks, runtime |
|---|---|---|---|

Run on its own it checks $D_\pm^2=-i\partial_\pm$, $\{D_+,D_-\}=0$, $\{Q,D\}=0$, $Q_\pm^2=i\partial_\pm$, the Berezin normalization, the exponential of a nilpotent element, the envelope sign rule and the graded Jacobi identity in $\mathfrak{gl}(2|1)$ | 9, seconds |
