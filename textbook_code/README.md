# Verification code for the textbook chapters

Scripts behind the symbolic and numerical checks of the textbook material in Parts I–IV (`part1-background/` to `part4-real-coupling/`) the textbook parts of Parts V–VI, and appendix A. Python 3 with numpy, sympy and mpmath. Each script runs on its own and prints one `PASS` or `FAIL` line per check.

## Figures (`figures/`)

Scripts that draw the matplotlib figures of the introduction and of Parts I to VI and check the formulas they plot. Python 3 with numpy, scipy and matplotlib. Each writes an SVG into the book tree (`figures/` for the introduction, `part1-background/figures/` for chapters 2–4, `part2-algebra/figures/` for chapters 5–8, `part3-classical/figures/` for chapters 9–11, `part4-real-coupling/figures/` for chapters 12–15, `part5-semiclassics/figures/` for chapters 16–19, `part6-soliton-smatrices/figures/` for chapters 20–27) and prints one `PASS` or `FAIL` line per check. The SVGs are committed, so building the book needs no Python. `style.py` holds the shared palette (mid-tone colours and grey text, transparent background, so that the figures read on both the light and the dark theme). Run one script with `python3 figures/<name>.py`, or all of them with `for f in figures/[ic]*.py; do python3 $f; done`.
