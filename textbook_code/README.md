# Verification code for the textbook chapters

Scripts behind the symbolic and numerical checks of the textbook material in Parts I–IV (`part1-background/` to `part4-real-coupling/`), the textbook parts of Parts V–VI, Part VII on the half-line (`part7-half-line/`; the `boundary_*`, `shg_boundary_*`, `reflection_matrices`, `qsp_checks`, `particle_reflection`, `soliton_preserving`, `an_nondiagonal_scalar`, `boundary_krein`, `dn_uniform`, `dn_nondiagonal_scalar`, `solitonic_linear`, `sp_scalar` and `boundary_dirichlet` scripts), Part VIII on defects (`part8-defects/`; the `defect_*` scripts) and appendix A. Python 3 with numpy, sympy and mpmath. Each script runs on its own and prints one `PASS` or `FAIL` line per check.

## Figures (`figures/`)

Scripts that draw the matplotlib figures of the introduction and of Parts I to IV and VII and check the formulas they plot. Python 3 with numpy, scipy and matplotlib. Each writes an SVG into the book tree (`figures/` for the introduction, `part1-background/figures/` for chapters 2–4, `part2-algebra/figures/` for chapters 5–8, `part3-classical/figures/` for chapters 9–11, `part7-half-line/figures/` for chapters 28–35) and prints one `PASS` or `FAIL` line per check. The SVGs are committed, so building the book needs no Python. `style.py` holds the shared palette (mid-tone colours and grey text, transparent background, so that the figures read on both the light and the dark theme). Run one script with `python3 figures/<name>.py`, or all of them with `for f in figures/[ic]*.py; do python3 $f; done`.
